МОИ ЗАМЕТКИ — исходный проект Android

Что умеет:
- голосовой ввод на русском языке через системную службу распознавания Android;
- добавление новых заметок в конец списка;
- редактирование текста;
- перемещение вверх и вниз;
- удаление с подтверждением;
- автоматическое сохранение в SharedPreferences на телефоне.

Важно:
Это исходный Android Studio проект, а не готовый APK. В этой среде нет Android SDK/Gradle,
поэтому APK здесь не собран и не протестирован на POCO M7 Pro 5G.

Как получить APK:
1. Установи Android Studio на компьютер.
2. Распакуй архив и открой папку MoiZametkiAndroid в Android Studio.
3. Дождись синхронизации Gradle и установки Android SDK 35 (если потребуется).
4. Выбери Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK обычно появится в app/build/outputs/apk/debug/app-debug.apk.
6. Передай APK на телефон, открой его и разреши установку из этого источника.
7. При первом голосовом вводе разреши доступ к микрофону.

Распознавание речи использует установленную на телефоне службу Android/Google и может
потребовать интернет-соединение в зависимости от её настроек. Сам текст заметок
сохраняется локально на устройстве.
